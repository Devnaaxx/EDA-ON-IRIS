 Exploratory Data Analysis on Iris Dataset

 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of the Iris Dataset using Python. The objective is to understand the dataset, explore patterns, identify relationships between features, and visualize the differences between Iris species.

 Technologies Used

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

 Project Workflow

1. Importing Libraries
2. Loading the Dataset
3. Data Exploration
4. Data Cleaning and Checking
5. Statistical Analysis
6. Data Visualization
7. Exploring Relationships Between Features
8. Drawing Insights from the Data

 Repository Files

* EDA -ON-IRIS.ipynb – Jupyter Notebook containing the Python code and analysis.
* EDA -ON-IRIS.html – HTML version of the notebook with outputs and visualizations.

 Project Objective

To gain practical experience in data analysis and visualization and understand how to extract meaningful insights from a dataset.
